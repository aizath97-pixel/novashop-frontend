**NovaShop - Sistema Web de Gestión Comercial y Facturación**



**Descripción General**

NovaShop es una solución web cliente-servidor orientada a la administración modular de productos, inventario, ventas POS y generación de reportes comerciales.



**Stack Tecnológico**

\- Frontend: HTML5, CSS3 (Tailwind CSS), JavaScript (ES6+)

\- Backend: Node.js, Express.js

\- Base de Datos: MySQL

\- Herramientas: Git, VS Code, Postman



**Estándares de Codificación**

\- Estilo: JavaScript Standard Style / ESLint

\- Nombramiento: camelCase (variables/funciones), PascalCase (clases)

\- Commits: Mensajes semánticos (`feat:`, `fix:`, `docs:`)



**Estructura del Proyecto**

\- `/src/controllers`: Manejadores de peticiones REST API.

\- `/src/services`: Lógica de negocio y reglas POO.

\- `/src/models`: Definición de entidades de la base de datos.

\- `/src/routes`: Enrutamiento modular.



**Configuración del Entorno**

1\. Clonar el repositorio: `git clone https://github.com/aizath97-pixel/novashop-frontend.git`

2\. Instalación de dependencias: `npm install`

3\. Iniciar servidor local: `npm run dev`
